# Class X Mathematics source fidelity: in progress

Official example source: https://files.akuebresources.com/2024/08/Mathematics-X-Paper-I-2021.pdf

The 2021 Paper I question text and choices were compared against rendered PDF
pages 2–14. Its 19 assigned diagrams were also reviewed individually against
those pages. Production repairs in this pass:

- Q5 and Q6: each question now includes the shared age data without a
  cross-question instruction.
- Q7: the first fraction is plain X/Y; only the later X and Y are barred.
  Its three fractions render vertically.
- Q12, Q15, Q16, Q21, Q24, Q30: corrected source transcription, option text,
  or answer keys. Q21 and Q24 had incorrect marked answers.
- Q27–28, Q30–31, Q34–35, Q42, Q48: replaced diagrams containing repeated
  options, PDF navigation text, clipped labels, or unrelated content.

Outside that paper, 2022 Paper I Q48–49 now omit PDF navigation text.
2023 Paper I Q20 has a graph without duplicate choices. 2024 Paper I Q18
has the source number line and answer choices; Q31–32 have a clean ladder
diagram.

The automated source audit covers all 282 Class X Mathematics records, but
text token overlap and image URL reachability do **not** establish exact
mathematical meaning or image fidelity. Its current report flags 87 diagrams
for further visual review. Four shared-context text records remain below the
parser's confidence threshold, and one source block is not parsed; these five
were inspected visually in this pass. The contact sheets generated by
`scripts/create-class-x-image-sheets.py` expose additional watermarks,
duplicated choices, and clipped labels in 2022–2025 papers. Do not report the
full Class X Mathematics collection as 100% confirmed until those records
are visually compared and repaired.
